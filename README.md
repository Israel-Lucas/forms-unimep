# Lista de Presença — Júri Simulado

Formulário para registrar nome completo e semestre. Os envios são armazenados na planilha configurada no Google Apps Script e encaminhados para vivian.milani@unimep.br.

## Configuração do Google Apps Script

O arquivo `google-apps-script.js` contém o endpoint que recebe os envios, grava os dados na aba `LISTA DE PRESENÇA JÚRI SIMULADO` e envia um e-mail com o assunto `LISTA DE PRESENÇA JÚRI SIMULADO`.

Após alterar o script no Google Apps Script, publique uma nova versão da implantação da Web App. O endereço da implantação usado pelo formulário está configurado em `script.js`.
